# QA Checklist

## Must pass

- It is 16:9 landscape.
- The background is a clean white base.
- Xiaohei is present.
- Xiaohei carries the core action, not just decoration.
- No old example composition reproduced; a new metaphor was generated for the current article.
- The image is bizarre, creative, interesting.
- Clean and simple; the subject is no more than about 60% of the canvas.
- One image conveys only one core structure.
- Chinese labels are few, short, and readable.
- Orange is used only for the main path or arrows.
- Red is used only for key points, problems, reminders, or results.
- Blue is used only for supplementary notes, feedback, or system state.

## Failure signals

If any of the following occur, regenerate or do a local edit:

- A top-left title such as "Common Pitfalls / Workflow / System Architecture / Roadmap".
- Xiaohei looks like a mascot, emoji, or cute cartoon.
- The image looks like a PPT, course slide, or formal flowchart.
- Too many elements, too many arrows, too many nodes.
- Text turns into long paragraphs of explanation.
- The background has paper texture, shadow, gradient, beige, or noise.
- Realistic UI screenshot or techy interface.
- Serious Chinese typos or unreadable labels.
- The image is too stiff, with no absurd metaphor.
- Too similar to an old composition in `assets/examples/`.

## Iteration methods

- Too plain: make Xiaohei the subject of the action and add a strange-but-coherent metaphor.
- Too complex: cut nodes, keep only one action and 3-5 short labels.
- Too cute: emphasize deadpan, blank serious expression, not cute, not mascot.
- Too PPT: remove the title, frames, neat grid, and excess arrows; switch to a hand-drawn scene.
- Too like an old case: keep the core meaning, swap the main object and Xiaohei's action.
- Wrong text: prefer a local edit; if there are many errors, regenerate and reduce the number of labels.

## Delivery judgment

A high-quality image should first make the reader feel "a bit weird", then let them grasp the structure within 1 second.

If it looks like a tutorial page at first glance rather than a bizarre product sketch on blank paper, it fails.
