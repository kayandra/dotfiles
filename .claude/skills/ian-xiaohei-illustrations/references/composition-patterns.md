# Composition Patterns and Originality Rules

## Base structure types

Pick one structure; don't mix too many.

### Workflow

Good for: input -> process -> output, content production, AI workflows, automation chains.

How to draw: input on the left, Xiaohei or a weird machine processing in the middle, output on the right, orange arrows for the main flow direction.

### System fragment

Good for: information sources, filters, databases, renderers, a slice of an agent system.

How to draw: draw only 3-5 core modules; Xiaohei takes part in one key action.

### Before/after contrast

Good for: chaos/order, manual/automatic, scattered/gathered, anxious/stable.

How to draw: chaos on the left, stability on the right, orange arrow in the middle. The character can be more exaggerated.

### Character state

Good for: user pain points, creator state, too many tools, information anxiety, stuck-to-running.

How to draw: 2-4 small states, one short label per state.

### Conceptual metaphor

Good for: content factory, information warehouse, mental black box, workflow machine, automated daily report.

How to draw: one big weird object or machine, a little input, one output. Make it memorable.

### Method layering

Good for: methodology frameworks, system hierarchies, capability stacks, content-system layers.

How to draw: stacked boxes, not a formal pyramid; Xiaohei hauling bricks or building beside it.

### Map / route

Good for: idea-to-launch, user paths, content handoff paths, learning roadmaps.

How to draw: one winding path, a few nodes, Xiaohei pulling a line or walking.

### Mini-comic panels

Good for: failure-to-success, the real process, gripes, before/after-use change.

How to draw: 2-4 small scenes, one action per panel.

## Original-metaphor generation method

Reinvent the metaphor from the current article every time; never copy old images.

### Three steps

1. Swap the abstract concept for a physical action: stuck, dropped, gets heavy, sorting, settling, fermenting, opening a door, folding, unpacking, flowing back.
2. Swap the system structure for a low-tech object: a broken machine, cardboard box, drawer, pipe, mailbox, weird dial, scale, well, ladder, strange workstation.
3. Let Xiaohei carry the action: not standing aside, but stuck in the machine, pulling the wrong line, guarding a gate, hauling, patching, weighing, holding the ladder, recording, stuffing something into some weird device.

### Usable object pool

- Cardboard box, drawer, old machine, funnel, scale, mailbox, door, well, ladder, pipe, ball of string, sluice gate, turntable, black box, hole punch, noodle press, clothesline, weird workstation.
- Use only 1-2 at a time; don't pile them up.

### Xiaohei action pool

- Pull, carry, stuff, scoop, press, weigh, sew, cut, twist, guard, push, catch, unpack, mark, recycle.
- The action must serve the core meaning; don't be weird just to be weird.

## Anti-copying rules

Don't open or reproduce `assets/examples/` by default. These images are only for style calibration, e.g. line density, white space, color restraint, Xiaohei's temperament.

Unless the user explicitly says "follow this one / reproduce this composition / edit using this case", don't directly reuse these old compositions:

- Two breakpoints on a conveyor belt
- Xiaohei pulling a judgment lever inside a content machine
- Xiaohei becoming a funnel sorting traffic/trust/conversion
- Xiaohei cutting the material fish
- Xiaohei leading a handoff path
- Xiaohei pulling three layers of information sources
- Three Xiaohei each holding a megaphone/building a bridge/opening a door
- Xiaohei stamping a copy toolbox
- Xiaohei holding a sign watching the common-pitfalls path

Use a fresh metaphor even for similar themes. For example, "handoff path" needn't be drawn as a route — you could draw Xiaohei hooking the content's tail onto a door handle; "one-fish-many-uses" needn't be a fish — you could draw Xiaohei pressing one paper wad into several shapes.
